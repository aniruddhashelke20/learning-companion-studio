# Deployment Guide

Three free-tier services: **MongoDB Atlas** (database) → **Render** (API server) → **Vercel** (client).
Total time: ~15 minutes.

## 1. MongoDB Atlas (database)

1. Sign in at https://cloud.mongodb.com and create a free **M0 cluster**.
2. **Database Access** → add a database user (username + password).
3. **Network Access** → *Allow access from anywhere* (`0.0.0.0/0`) — required so Render can connect.
4. **Connect → Drivers** → copy the connection string, e.g.
   `mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/learnlog?retryWrites=true&w=majority`
   (add the `/learnlog` database name before the `?`).

## 2. Render (API server)

1. Push this repo to GitHub (your fork).
2. Sign in at https://render.com → **New → Blueprint** → connect the repo.
   Render reads `render.yaml` and creates the `learning-companion-api` web service.
   (Or create a plain **Web Service** manually: root directory `server`, build `npm install`, start `npm start`.)
3. Set environment variables:
   - `MONGODB_URI` — the Atlas string from step 1
   - `CLIENT_URL` — your Vercel URL (fill in after step 3; then redeploy)
   - `JWT_SECRET` — auto-generated by the blueprint
4. After the first deploy, **seed the database** (one time). In the Render *Shell* tab:
   ```bash
   npm run seed
   ```
   This creates the demo accounts and the three LCM courses.
5. Note the service URL, e.g. `https://learning-companion-api.onrender.com`.
   Check `https://<your-service>.onrender.com/api/health` returns `{"status":"ok"}`.

## 3. Vercel (client)

1. Sign in at https://vercel.com → **Add New → Project** → import the same GitHub repo.
2. Set **Root Directory** to `client` (framework auto-detects Vite).
3. Add environment variable:
   - `VITE_API_URL` = `https://<your-render-service>.onrender.com/api`
4. Deploy. Note the URL, e.g. `https://learning-companion-studio.vercel.app`.
5. Go back to Render and set `CLIENT_URL` to this exact URL (no trailing slash) so CORS allows the client. Redeploy the API.

## 4. Verify & share

Open the Vercel URL and sign in with the demo accounts:

| Role | Email | Password |
|---|---|---|
| Content Author | `author@learningcompanion.studio` | `AuthorPass123!` |
| Learning Companion | `companion@learningcompanion.studio` | `LearnerPass123!` |
| Admin / Mentor | `admin@learningcompanion.studio` | `AdminPass123!` |

Demo flow for the client meeting:
1. Log in as **author** → Authoring Desk → open a course → edit a reflection spot / LbD feedback → **Save lesson & sync**.
2. Log in as **companion** (incognito window) → open the same lesson → the change is live.
3. Show LeD reflection spots, LbD instant feedback, subjective exemplar comparison, LxT resources, LxI cohort prompt, and the review quiz.

> Note: Render's free tier sleeps after inactivity — the first request after a while takes ~30–60 s. Open the site a few minutes before the demo.

## Local development

No MongoDB needed — the server falls back to an in-memory database (auto-seeded, resets on restart):

```bash
cd server && npm install && npm run dev     # API on :5050 (in-memory DB if no MONGODB_URI in .env)
cd client && npm install && npm run dev     # client on :5173
```
