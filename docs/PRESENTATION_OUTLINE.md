# Presentation outline

1. **Problem** — Learning systems need more than page views: they need meaningful engagement data.
2. **Solution** — LearnLog: learning experience plus event pipeline in a single full-stack app.
3. **User journey** — Authenticate → choose a course → learn → quiz → receive score.
4. **Event design** — Event context, component, event name, resource, metadata, origin, IP, timestamp.
5. **Architecture** — React/Vite client → Express API → MongoDB collections.
6. **Analytics** — Aggregate learner adoption, participation, scores, and frequently occurring actions.
7. **Live demo** — Follow `DEMO_SCRIPT.md`.
8. **Future work** — Completion progress, instructors, exports, privacy retention controls, more courses.
