# Suggested Git history

1. `chore: initialize monorepo and development tooling`
2. `feat(api): add authentication and learning data models`
3. `feat(api): record Moodle-style learning events and quiz attempts`
4. `feat(web): build learner dashboard lessons and quizzes`
5. `feat(analytics): add administrator activity dashboard`
6. `docs: add local setup demo script and architecture notes`

If the repository is initialized after the project is written, create these commits by staging the appropriate areas in order, rather than backdating files.
