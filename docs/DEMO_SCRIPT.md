# 3-minute demo script

1. Sign in as **Harvey Learner** and show the course dashboard.
2. Open *Introduction to Machine Learning*; explain that this creates a `COURSE_VIEWED` event.
3. Open the supervised-learning lesson; scroll the page and point out that meaningful learning behaviour is tracked automatically.
4. Take the quiz. Submit answers and show that the server returns a score and saves an attempt.
5. Sign out and sign in as **Platform Admin**.
6. Open Analytics. Show total learners, average score, active users, common event chart, and the recent-event table.
7. Explain that the log mirrors Moodle fields so analysts can answer engagement questions without recording every raw click.
